# What If channel

Workspace for a YouTube channel of "What if...?" videos with simple flat-color animations, made
with Claude Code.

Start a Claude Code session on this repo and it picks up where the last one left off:
`CLAUDE.md` holds the channel decisions and `youtube/episodes.md` tracks every episode.

## What's inside

- `.claude/skills/`: YouTube skills (`/yt-script`, `/yt-package`, `/yt-seo`, `/yt-chapters`,
  `/yt-shorts`, ...), Ponytail (`/ponytail`, `/ponytail-review`, ...) and Headroom.
- `youtube/voice.md`: the narrator's voice profile (draft).
- `youtube/episodes.md`: episode tracker and idea backlog.
- `scripts/install-headroom.sh`: wrap Claude Code with Headroom on your own computer.
- `third_party/`: sources, versions and licences of the bundled skills.
